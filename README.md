# UberEats-Clone / Master Talent CR

Se agregó un prototipo visual navegable en `preview/` con:

- PYMES y emprendimientos en lugar de restaurantes.
- Categorías: comidas, servicios, arte y turismo.
- Banner hero animado con la paleta del logo.
- Botones con sombras, estados hover y mensajes interactivos.
- Búsqueda y filtrado de emprendimientos.
- Diseño responsive para móvil y escritorio.

Para verlo: abre `preview/index.html` directamente en el navegador o sirve la carpeta con un servidor local, por ejemplo `python -m http.server 8000` dentro de `preview/`, y visita `http://localhost:8000`.

El prototipo es una vista visual; la autenticación, base de datos, pagos y paneles se conectarán después al proyecto Blazor real. Sustituye el logotipo CSS del encabezado por el archivo PNG oficial cuando esté disponible en `wwwroot/images/logo.png`.
